# Art of Lime - Modern Full-Page Portfolio

A stunning, modern portfolio website for Art of Lime business featuring full-page sections, smooth scrolling, and interactive galleries.

## ✨ Features

### 🎯 Full-Page Sections

- **Smooth Section Snapping**: Each scroll automatically moves to the next complete section
- **Custom Scroll Behavior**: Hijacked scrolling with smooth easing animations
- **Keyboard Navigation**: Arrow keys, Page Up/Down, Home/End support
- **Touch Gestures**: Mobile-friendly swipe navigation

### 🧭 Side Navigation

- **Interactive Dots**: Click to jump to any section instantly
- **Active Indicators**: Visual feedback showing current section
- **Hover Labels**: Section names appear on hover
- **Mobile Optimized**: Adapted for smaller screens

### 🖼️ Custom Gallery

- **Before/After Filter**: Toggle between transformation states
- **Lightbox View**: Full-screen image viewing with navigation
- **Keyboard Controls**: ESC to close, arrows to navigate
- **Responsive Grid**: Adaptive layout for all screen sizes
- **Loading Animations**: Staggered reveal effects

### 🎨 Modern Design

- **Beautiful Gradients**: Eye-catching color schemes
- **Smooth Animations**: Fade-ins, slide-ups, and hover effects
- **Glass Morphism**: Modern backdrop blur effects
- **Loading Screen**: Professional startup experience
- **Progress Indicator**: Visual scroll progress tracking

## 🚀 Getting Started

### Development server

```bash
npm start
```

Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

### Build

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.
